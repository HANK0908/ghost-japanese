鬼日文筆記本 Mobile PWA（零付費 API）
手機安裝：需先把整個資料夾部署到 HTTPS 靜態網站（例如 GitHub Pages 或 Cloudflare Pages）。
iPhone：用 Safari 開啟網址 → 分享 → 加入主畫面。
Android：用 Chrome 開啟網址 → 選單 → 安裝應用程式／新增至主畫面。
注意：直接把 index.html 傳到手機開啟，無法當作正式可安裝 PWA。
框選洗腦：先建立筆記 → 🎧 框選洗腦 → 勾選項目 → 選 ×3/×5/×10 → ▶️。
本機儲存，不跨裝置同步。務必定期匯出 JSON 備份。
iOS 的語音播放可能因鎖屏、切換應用或系統限制而中斷，不能保證背景連續播放。
